# React Calculator

A simple React calculator that supports addition, subtraction, multiplication, and division. It also includes separate controls to reset the input fields and clear the displayed result.

## Requirements

- Node.js and npm

## Run locally

```bash
npm install
npm start
```

The development server normally opens at http://localhost:3000.

## Included functionality

- React `useState` for the displayed result
- React `useRef` to read and reset the input fields
- Addition, subtraction, multiplication, and division
- Division-by-zero handling
- Separate Reset Inputs and Reset Result buttons
